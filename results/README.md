# Reproducibility outputs

This directory contains the saved outputs from the final matched-seed experiment configuration:

- `config.json`: complete simulator/training configuration
- `raw_results.csv`: per-seed/per-method/per-scenario metrics
- `summary.csv`: aggregated metrics
- `training_history.csv`: rollout-level RL training history
- `figures/`: figures generated directly by the experiment runner

Large neural-network checkpoint files are omitted from this GitHub snapshot. They can be regenerated by running the full experiment command from the repository root.
